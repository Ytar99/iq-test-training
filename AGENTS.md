# Тренажер ТИПС

Сначала читай [docs/todo.md](docs/todo.md), затем [docs/spec.md](docs/spec.md). Этот файл поведение продукта не пересказывает.

В todo только то, что еще нужно сделать. Сделанный пункт удаляется, история изменений не ведется. Незакрытый пункт говорит, какое правило еще предстоит записать в спецификацию и какому правилу следует код. Готовое правило читается из спецификации. При расхождении готового правила верна спецификация.

Перед изменением экранов, таймеров, банка, сборки попытки или итога прочитай todo и спецификацию.

Сборка: pnpm. UI: Mantine v9. Перед компонентами, темой и стилями смотри skills в `.agents/skills` и MCP `mantine`. Пропсы бери из документации, не по памяти.

Публикация: статический `pnpm build` на GitHub Pages. Локально base `/`, в Actions base `/${repository}/`.
